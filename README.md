# Pet Adoption & Responsible Pet Care Website

## About the Project
This is a web-based Pet Adoption and Responsible Pet Care website developed to help users explore pets available for adoption and learn about responsible pet care.

## Features
- Browse available pets
- Search and filter pets
- View individual pet information
- Online adoption request form
- Contact form
- Pet care information
- Responsive and user-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite

## Project Purpose
The main purpose of this project is to promote pet adoption and provide useful information about responsible pet care through a simple and user-friendly website.

## How to Run
1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `npm install`
5. Start the server using `node server.js`
6. Open the website in your browser.
